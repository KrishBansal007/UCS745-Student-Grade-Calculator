# Student Grade Calculator

A small Python command-line application that calculates a student's average marks and assigns a letter grade.

## Features
- Accepts a student name.
- Accepts marks for multiple subjects.
- Validates that marks are between 0 and 100.
- Calculates the average and assigns a grade.

## Requirements
- Python 3.8 or later
- No third-party packages

## Run
```bash
python3 grade_calculator.py
```

## Example
```text
STUDENT GRADE CALCULATOR
------------------------
Enter student name: Krish
Enter marks separated by spaces (0-100): 85 90 78

RESULT
Student: Krish
Number of subjects: 3
Average: 84.33
Grade: B
```
